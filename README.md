# Art Project - Kunstgeschiedenis Website

Een uitgebreide website over 20+ kunststromingen van Byzantijnse Kunst tot Pop Art.

## 🎨 Kunststromingen

- Byzantijnse Kunst (330-1453)
- Romaanse Kunst (800-1200)
- Gotische Kunst (1140-1500)
- Renaissance (1400-1600)
- Maniërisme (1520-1620)
- Barok (1600-1750)
- Neoclassicisme (1750-1850)
- Romantiek (1780-1850)
- Realisme (1840-1880)
- Impressionisme (1860-1890)
- Post-Impressionisme (1880-1900)
- Art Nouveau (1890-1910)
- Expressionisme (1905-1930)
- Kubisme (1907-1914)
- Dadaïsme (1916-1924)
- De Stijl (1917-1931)
- Surrealisme (1924-1966)
- Abstract Expressionisme (1940-1960)
- Pop Art (1955-1970)
- Postmodernisme (1970-2000)

## 🚀 Deployment

Automatische deployment via GitHub Actions naar matthiasr.com/art

## 📁 Structuur

```
/
├── index.html              # Homepage met timeline
├── style.css               # Global styles
├── [movement].html         # Per kunststroming
└── images/
    └── [movement]/         # Afbeeldingen per stroming
```

## 🔧 Technologie

- HTML5
- CSS3 (responsive)
- Vanilla JavaScript
- GitHub Actions (CI/CD)
