# 10 Nieuwe Kunststromingen - Kunstgeschiedenis Project

## Geselecteerde Stromingen (chronologisch):

1. **Renaissance** (1400-1600)
   - Focus: Humanisme, perspectief, anatomische precisie
   - Key artists: Leonardo, Michelangelo, Raphael, Botticelli

2. **Barok** (1600-1750)
   - Focus: Drama, beweging, licht/donker (chiaroscuro), emotie
   - Key artists: Caravaggio, Rembrandt, Rubens, Bernini

3. **Realisme** (1840-1880)
   - Focus: Alledaagse werkelijkheid, sociale kritiek, ongeïdealiseerd
   - Key artists: Courbet, Millet, Daumier

4. **Impressionisme** (1860-1890)
   - Focus: Licht, kleur, momentopname, losse penseelvoering
   - Key artists: Monet, Renoir, Degas, Pissarro

5. **Post-Impressionisme** (1880-1900)
   - Focus: Structuur, symboliek, emotionele expressie, kleurtheorie
   - Key artists: Van Gogh, Cézanne, Gauguin, Seurat

6. **Art Nouveau** (1890-1910)
   - Focus: Organische vormen, natuur, decoratief, sinuositeit
   - Key artists: Mucha, Klimt, Horta, Guimard

7. **Surrealisme** (1920-1950)
   - Focus: Droomwereld, onbewuste, automatisch schrijven/schilderen
   - Key artists: Dalí, Magritte, Miró, Ernst

8. **Abstract Expressionisme** (1940-1960)
   - Focus: Abstractie, spontaniteit, grootformaat, emotionele intensiteit
   - Key artists: Pollock, Rothko, de Kooning, Kline

9. **Pop Art** (1950-1970)
   - Focus: Massacultuur, reclame, comic strips, herhaalde beelden
   - Key artists: Warhol, Lichtenstein, Hockney, Hamilton

10. **Minimalisme** (1960-1970)
    - Focus: Eenvoud, geometrische vormen, industriële materialen, reductie
    - Key artists: Judd, Serra, Andre, Flavin

## Planning:
